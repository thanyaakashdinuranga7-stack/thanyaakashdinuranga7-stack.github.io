THANYA AKASH DINURANGA — DIGITAL PORTFOLIO
===========================================

FILES
- index.html: main responsive portfolio page
- assets/profile.png: uploaded profile portrait
- certificates/: certificate PDFs, linked locally (not Google Drive)

PREVIEW
Open index.html in a browser. Internet is needed for Google Fonts and Font Awesome icons.

PUBLISH ON GITHUB PAGES
1. Sign in to GitHub and open your repository: thanyaakashdinuranga7-stack.github.io
2. Upload index.html, the assets folder, the certificates folder, and this README.
   IMPORTANT: Upload the folders and their contents, not just index.html.
3. Commit changes to the main branch.
4. In repository Settings -> Pages, select Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for GitHub Pages to publish. The certificates will open from your website at /certificates/...

PRIVACY / CHECK BEFORE PUBLISHING
- I deliberately did not include your NIC number, full home address, or referees' private phone numbers.
- Confirm your employment date/status, A/L status, membership claims and all contact links before publishing.
- The CV button is a mailto “Request CV” link because no public CV PDF/DOCX was supplied. Replace it with a file link if you want a direct download.
- This website uses the certificate PDFs supplied in this chat. Once deployed, they are public to anyone who has the website URL.
